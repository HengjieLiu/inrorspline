# LungCT MR-D-BSCP 1 mm acceleration and timing

This directory contains the experiment specification, technical limitations,
manifests, and compact review tables for the six-variant 4DCT/COPD campaign.
Large fields, checkpoints, logs, and runtime outputs remain under the external
experiment root and are not committed here.

The report compares all cases individually and aggregates TRE over the ten
cases. Timing reports cold case 1, warm cases 2-10, and the all-ten average for
each dataset/variant cohort.
